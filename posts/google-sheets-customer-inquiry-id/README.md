# google-sheets-customer-inquiry-id assets

이 폴더는 Blogger 글 `구글시트에서 고객번호·문의ID 자동 생성하는 방법`의 본문 이미지를 보관합니다.

자동화 표준 파일명:

1. `01.png` — 고객ID와 문의ID 관계도
2. `02.png` — CRM 시트 구조
3. `03.png` — ID 처리 흐름도
4. `04.png` — 고객ID 수식 예시
5. `05.png` — Apps Script 고객ID 자동 생성
6. `06.png` — 전화번호 정규화

발행 스크립트는 원고 파일명(slug)과 이미지 번호를 기준으로 공개 URL을 자동 계산합니다.

예시:

`posts/google-sheets-customer-inquiry-id.md`

→

`https://raw.githubusercontent.com/dmsy1009-eng/blogger-assets/main/posts/google-sheets-customer-inquiry-id/01.png`

따라서 원고에는 별도 이미지 URL을 입력하지 않아도 됩니다. 본문에 `> 이미지 1 삽입 위치: ...` 또는 `[이미지 1 삽입]` placeholder만 있으면 됩니다.
